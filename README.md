# Joules Burn’s Pie Chart v0.1.013

Focused orientation update from v0.1.012. The portrait mode now uses the exact same **upright** chart (time left to right, live labels on the right) as landscape, responsive to the narrower screen. No rotated portrait graph, no distinct 7-day mode.

All other functions and the editable dummy-data.csv are carried over.

Publish the files in this folder to GitHub Pages and install as a PWA for fullscreen.
